# TontineChain 🔗💰

**TontineChain** est une application décentralisée (dApp) innovante conçue pour moderniser l'épargne communautaire (tontine) en utilisant la puissance de la technologie Blockchain. 

Notre solution apporte une **transparence totale**, une **sécurité immuable** et élimine le besoin d'un tiers de confiance pour la gestion des fonds.

---

## 🚀 Vision du Projet
La tontine traditionnelle repose sur la confiance humaine, ce qui peut mener à des litiges ou des détournements. **TontineChain** remplace cette confiance par du code (Smart Contract), garantissant que chaque membre cotise et que chaque bénéficiaire reçoit sa cagnotte à la date prévue, sans interférence possible.

---

## ✨ Fonctionnalités Principales
- **Intégration Web3** : Connexion fluide avec les portefeuilles crypto (MetaMask) via Ethers.js.
- **Initialisation Blockchain** : Chaque tontine déploie une instance unique d'un Smart Contract Solidity sur la blockchain.
- **Tableau de Bord Premium** : Interface moderne avec des visualisations dynamiques (Chart.js) de la progression de l'épargne.
- **Gestion des Rounds** : Système automatique de suivi des bénéficiaires et des tours de table.
- **Archives Immuables** : Historique complet des anciens rounds consultable à tout moment.
- **Journal de Bord Blockchain** : Log en temps réel de toutes les transactions (Cotisations, Libérations) avec horodatage.
- **Design Responsive** : Optimisé pour une utilisation sur Smartphone, Tablette et Ordinateur.

---

## 🛠️ Stack Technique
- **Frontend** : HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Bibliothèques JS** : 
  - [Ethers.js](https://docs.ethers.org/) pour l'interaction Blockchain.
  - [Chart.js](https://www.chartjs.org/) pour les visualisations dynamiques.
- **Smart Contract** : Solidity v0.8.x
- **Déploiement** : [Vercel](https://vercel.com/) pour l'hébergement continu.

## 📦 Installation & Utilisation

### Pré-requis
- Un navigateur moderne (Chrome, Brave, Firefox).
- L'extension [MetaMask](https://metamask.io/) installée.

### Installation Locale
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Mechac-2004/tontinechain.git
   ```
2. Ouvrir le dossier :
   ```bash
   cd tontinechain
   ```
3. Lancer un serveur local (exemple avec PHP ou Live Server) :
   ```bash
   php -S localhost:8080
   ```
4. Ouvrir `http://localhost:8080` dans votre navigateur.

---

## 📖 Instructions d'Utilisation (Démo)
1. **Connect Wallet** : Cliquez sur le bouton en haut à droite pour lier votre compte MetaMask.
2. **Configuration** : Remplissez le nom de la tontine, le montant et sélectionnez les membres.
3. **Déploiement** : Cliquez sur "INITIALISER SUR LA BLOCKCHAIN" pour activer le contrat.
4. **Gestion** : Sélectionnez votre tontine dans la liste pour effectuer les cotisations.
5. **Libération** : Une fois la cagnotte à 100%, libérez les fonds vers le bénéficiaire d'un simple clic.
