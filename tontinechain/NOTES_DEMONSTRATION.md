# Notes de Démonstration - TontineChain (Pitch 10 min)

Ce document est votre guide pour l'enregistrement de votre vidéo.

## 🟢 1. Préparation (Avant de filmer)

- Assurez-vous que **MetaMask** est connecté à un réseau de test (Sepolia par exemple).
- Ayez au moins **deux comptes** MetaMask prêts pour simuler deux membres.
- Réinitialisez la base de données (si vous voulez partir d'un écran vide).

## 🕒 0:00 - 1:30 : L'Introduction (L'Impact)

- **ACTION** : Affichez la page d'accueil de TontineChain.
- **À DIRE** : "Bonjour à tous. Saviez-vous qu'au Bénin, les tontines représentent un marché informel de **400 à 600 millions de dollars** par an ? C'est le pilier de l'épargne locale. Pourtant, des millions disparaissent chaque année faute de traçabilité. Voici **TontineChain**, la solution qui sécurise l'épargne communautaire grâce à la Blockchain."

## 🕒 1:30 - 3:00 : Connexion & Configuration

- **ACTION** : Cliquez sur **"Connect Wallet"**. Montrez la fenêtre MetaMask s'ouvrir et la connexion réussir.
- **À DIRE** : "Ici, pas de mot de passe complexe qui peut être volé. Votre identité est votre Wallet. Dès que je suis connecté, le système reconnaît mes privilèges et mes tontines."

## 🕒 3:00 - 5:00 : Création d'une Tontine

- **ACTION** : Créez une nouvelle tontine (ex: "Tontine des Entrepreneurs"). Sélectionnez 3 membres, fixez un montant (ex: 10 000 FCFA).
- **À DIRE** : "Créer une tontine est devenu un jeu d'enfant. Je choisis mes membres, mon montant, et TontineChain calcule tout. Tout est sauvegardé en temps réel dans notre base de données sécurisée."

## 🕒 5:00 - 8:00 : Le Paiement Blockchain (Le "Wow" Effect)

- **ACTION** : Allez dans le détail de la tontine. Cliquez sur **"Payer"**. Montrez la transaction MetaMask à 0 ETH. Attendez la confirmation.
- **À DIRE** : "C'est ici que la magie opère. Lorsque je paye ma cotisation, une transaction est inscrite sur la Blockchain. Vous voyez ce Hash ? C'est une preuve indélébile. Personne ne pourra dire que je n'ai pas payé."
- **ACTION** : Montrez le badge **"Paiements complets"** ou le journal des événements.

## 🕒 8:00 - 10:00 : Conclusion & Vision

- **ACTION** : Montrez le Dashboard (graphique circulaire).
- **À DIRE** : "Grâce à cette visibilité totale, nous pouvons sécuriser les 600 millions de dollars du marché béninois. Nous réduisons les risques de fraude de 90%. Prochaine étape : les smart contracts pour l'auto-versement des fonds. Merci de votre attention."
